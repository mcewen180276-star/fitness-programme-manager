FITNESS PROGRAMME MANAGER v44 — FOOD & HYDRATION DIARY

New: Trainer-side Food & hydration page, per-client feature toggles, optional diary in exported Client Companion mini-app, descriptive food and drink entries, optional compressed local photos, diary history, client-initiated diary export, and trainer-side import for the selected client. Photos are NEVER included in exported diary JSON. Diary is disabled by default; enable for each client, save settings and export a NEW Client Companion.

Existing client records and all v43 functionality are retained. Existing localStorage key is unchanged. New diary data is added as separate fields.

Privacy: Browser storage is not a secure medical record system. Diary export JSON is NOT encrypted; share only with explicit permission. Do not put sensitive client information into filenames or share public links. The app has no automatic cloud sync. Client data stays on the device until deliberately exported. Photo storage is limited by browser storage capacity.

IMPORTANT: Before updating, export an encrypted backup from the old app. Upload all ZIP contents to the root of your GitHub Pages repository. Do not uninstall or clear browser data.
