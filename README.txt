FITNESS PROGRAMME MANAGER v45 — COACHING SYSTEM UPGRADE
========================================================
Upload all files and the icons folder to the ROOT of your existing GitHub Pages repository.
Do not clear Chrome storage, uninstall the app or overwrite data without first downloading an encrypted backup from Backup & Privacy.
Keep the existing repository address, manifest ID, and browser storage key.

NEW:
- Approved minimalist navy/blue dumbbell + check icon in 192/512 and maskable Android formats.
- Client Journey: profile, goals, separate programme, training, assessments, diary, challenges and recovery links.
- Smart Programme Assistant: training goal, equipment and day preferences, linked to existing adult-screened draft generator.
- Exercise Equipment Manager: custom equipment labels, library equipment inventory, and suggested alternatives; existing search, online import, and duplicate audit remain.
- Training Review: per-client training history with previous matching workout comparisons.
- Professional Coaching Review: client/period summary, comments, next steps and print.
- Client Companion: new Home screen and quick links to programme, workout logging, progress and optional diary.
- Safety: two rotating local recovery snapshots approximately every 15 minutes when saving, plus explicit snapshots before selected programme replacements, manual snapshot, restore confirmation, and existing programme version history.
- All v44 sections and functionality retained.

LIMITATIONS:
- Automatic snapshots are stored only in the same browser/device and may fail if storage is full. They are NOT a substitute for downloadable encrypted backups.
- Recovery snapshots are not encrypted. Protect the device and do not use sensitive client information without appropriate data protection arrangements.
- The programme assistant does not use paid AI and does not automatically change the client profile or guarantee suitability. Adult readiness screening and trainer review remain necessary.
- Custom equipment labels and alternatives are local; third-party exercise databases may not recognise them.
- Client mini-app exports and result files remain unencrypted and must be shared privately.
- Syntax validated, but Android browser interaction and GitHub Pages publication still require user testing.
